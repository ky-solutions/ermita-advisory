# Assets du kit Ermita Advisory

## Utilisation
Copier assets/ dans public/ du projet. Charger les polices avec next/font/local. Les maquettes restent des références, elles ne doivent pas être affichées comme pages.

- assets/fonts/DMSerifDisplay-Regular.ttf : titres, graisse 400.
- assets/fonts/Inter-Variable.ttf : corps et UI, plage 100–900.
- Les fichiers OFL accompagnent les polices et doivent être conservés.
- assets/brand/favicon.svg : favicon vectoriel proposé, e et accent bleu, distinct du logo complet.
- assets/icons/*.svg : flèches, menu et fermeture ; tracés originaux simples, couleur currentColor, décoratifs avec aria-hidden lorsqu’un libellé est présent.
- design-tokens.css : variables de couleurs et dimensions de départ.

## Provenance
Polices téléchargées du dépôt officiel Google Fonts :
https://github.com/google/fonts/tree/main/ofl/dmserifdisplay
https://github.com/google/fonts/tree/main/ofl/inter
Licences SIL Open Font License incluses.

Photographies : images créées par IA pour ce projet, architecture illustrative. Elles ne représentent pas les locaux d’Ermita et ne reproduisent pas exactement les photographies contenues dans les maquettes.
Logo : création proposée dans cette conversation. Version PNG transparente destinée à l’intégration ; pas un logo vectoriel final. Vérifier son rendu à petite taille.

Les fichiers WebP sont des conversions des originaux générés. Conserver les originaux PNG pour les modifications futures.
